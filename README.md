# Печатает…

Интерактивный лонгрид о присутствии, интонации и общении в мессенджерах.

Автор — Карина Манукян. Куратор — Олег Пащенко.

## Запуск

Сборка и установка зависимостей не требуются. Запустите из корня репозитория:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000 в браузере.

## Файлы

- `index.html` — экраны лонгрида и источники.
- `styles.css` — оформление и адаптация для телефона.
- `*.js` — анимации, интерактивы и типографика.
- `assets/` — фоновые изображения, портреты, иллюстрации, шрифты и локальные библиотеки.

Анимации используют GSAP и ScrollTrigger из `assets/`. Предусмотрен режим уменьшенного движения. Содержимое репозитория можно разместить на статическом хостинге.
